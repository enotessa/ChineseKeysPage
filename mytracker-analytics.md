# События MyTracker

SDK key: `00586517499712531010`

## События

| Событие | Когда отправляется | Параметры |
| --- | --- | --- |
| `onboarding_completed` | Онбординг завершён | — |
| `screen_opened` | Открыт экран | `screen`, опционально `content_id`, `step` |
| `lesson_started` | Пользователь начал урок | `content_id` |
| `quiz_answered` | Выбран первый ответ в тесте | `content_id`, `correct` |
| `writing_step_completed` | Завершён этап письма | `content_id`, `step`, `source` |
| `lesson_completed` | Завершены все этапы письма нового ключа | `content_id` |
| `pronunciation_completed` | Завершено упражнение произношения | `content_id`, `source` |
| `review_completed` | Завершено упражнение повторения | `content_id`, `exercise`, `result` |
| `language_changed` | Изменён язык интерфейса | `language` |

`content_id` — внутренний идентификатор учебного ключа, а не идентификатор пользователя.

## Ограничения приватности

В MyTracker не передаются имя и пол пользователя, поисковые запросы, нарисованные линии,
аудиозаписи и результаты распознавания речи. Новые события следует добавлять только через
`AppAnalytics`, сохраняя параметры короткими и контролируемыми приложением.
