# Чек-лист релиза Google Play

- [ ] Заменить контактный email в `privacy-policy-ru.md`.
- [ ] Разместить политику конфиденциальности на публичном HTTPS-адресе.
- [ ] Создать upload key и сохранить `.jks` и пароли вне репозитория с резервной копией.
- [ ] Подключить Play App Signing.
- [ ] Настроить и проверить согласие на обработку рекламных данных для нужных регионов.
- [ ] Проверить production ID рекламных блоков в РСЯ.
- [ ] Заполнить Data safety с учётом Yandex Mobile Ads SDK, MyTracker SDK и микрофона; отдельно отметить передаваемые MyTracker идентификаторы устройства.
- [ ] В MyTracker открыть вкладку «Статус интеграции» и проверить получение запуска и тестовых событий из internal testing.
- [ ] Указать наличие рекламы в разделе App content.
- [ ] Заполнить декларацию Advertising ID, если разрешение присутствует в итоговом manifest.
- [ ] Заполнить возрастную категорию и анкету Content rating.
- [ ] Добавить email поддержки и при необходимости сайт.
- [ ] Загрузить иконку 512×512, feature graphic 1024×500 и минимум 2 скриншота.
- [ ] Протестировать signed release bundle на физическом устройстве через internal testing.
- [ ] Для нового личного аккаунта выполнить требования закрытого тестирования перед production.
- [ ] Перед каждым обновлением увеличивать `versionCode`.
